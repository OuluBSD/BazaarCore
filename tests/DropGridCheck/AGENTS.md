# DropGridCheck Package Guide

**Parent Assembly**: `OuluBSD/BazaarCore`  
**Namespace**: `Upp`  
**Dependencies**: `CtrlLib`, `GridCtrl`, `DropGrid`

---

## 1. Package Purpose

`DropGridCheck` is an automated test suite verifying the runtime behavior of the `DropGrid` control:
- Table column configuration and dimensions.
- Row insertion with multi-column values.
- Key, value, and find column binding.
- Value lookup, selection, cursor traversal, and key-based retrieval.
- Clear and reset lifecycles.
